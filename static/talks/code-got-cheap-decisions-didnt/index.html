# Title the talk "Code Got Cheap, Decisions Didn't" accepted

## Context The organisers needed a title. The audience doesn't know the project, so the title has to name the subject as well as the claim.

## Considered options

  • "Code Got Cheap, Decisions Didn't"
  • "When Code Is Cheap, Decisions Are Expensive"
  • "The Build Got Fast. Then What?"

## Decision "Code Got Cheap, Decisions Didn't", because it states the claim, and its second half names the subject.

## Consequences Bad, because "Decisions Didn't" is a promise: the talk has to show what decisions cost, with numbers.
